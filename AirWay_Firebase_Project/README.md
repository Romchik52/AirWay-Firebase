# AirWay — Firebase airline booking project

Учебный веб-проект системы поиска и бронирования авиабилетов. Основной стек: HTML, CSS, JavaScript ES Modules и Firebase Authentication + Cloud Firestore.

## Запуск

1. Откройте папку `AirWay_Firebase_Project` в VS Code.
2. Запустите `index.html` через **Live Server**.
3. Не открывайте проект двойным кликом через `file://`.

## Firebase Authentication

В Firebase Console для проекта необходимо включить:

- Authentication → Sign-in method → Email/Password.
- Authentication → Settings → Authorized domains → `localhost` для локальной разработки.

## Firestore

Необходимо создать Cloud Firestore Database и применить:

- `firestore.rules`
- `firestore.indexes.json`

После обновления правил часть пользовательских операций работает только при авторизованной сессии.

- регистрация и вход по Email/Password;
- восстановление пароля;
- сохранение сессии;
- поиск рейсов по маршруту, дате и пассажирам;
- фильтры по авиакомпании, классу и пересадкам;
- сортировка;
- cursor pagination;
- популярные направления;
- Firebase и демо-рейсы;
- добавление рейса в корзину;
- количество пассажиров в корзине;
- форма данных пассажиров;
- атомарное бронирование Firebase-рейса;
- электронный билет;
- QR-код билета;
- печать / сохранение билета через системный PDF-принтер;
- история бронирований в realtime;
- отмена бронирования с возвратом места;
- возврат отменённого билета в корзину с повторной проверкой доступности рейса;
- скрытие отменённого билета из личной истории без удаления записи из Firestore;
- отзывы;
- личный профиль;
- адаптивная мобильная версия.

### Администратор
- dashboard со статистикой;
- управление рейсами;
- управление ценой и местами;
- добавление демо-рейсов в Firestore;
- постраничная загрузка таблиц;
- поиск и фильтрация заказов;
- изменение статусов заказов;
- корректировка свободных мест при отмене/повторном подтверждении;
- управление пользователями и ролями;
- модерация отзывов;
- журнал действий.

## Электронный билет

Для QR-кода используется небольшая клиентская библиотека QRCode.js через jsDelivr. Интернет нужен для её загрузки так же, как для Firebase CDN.

Если QR-библиотека недоступна, интерфейс билета показывает безопасный fallback вместо падения страницы.

## Важно для защиты

Демо-рейсы нужны для локальной демонстрации. Для полноценного теста Firebase-части администратор может открыть Admin → Рейсы → `+ Демо-рейсы`. После этого рейсы будут сохранены в Firestore и смогут проходить реальный транзакционный цикл бронирования.


### Версия v4
- Улучшен поиск по произвольному маршруту: теперь формируется несколько вариантов вместо одного.
- Выбранный сгенерированный рейс сохраняется при переходе на страницу подробностей.

### Версия v7
- В «Мои билеты» добавлен возврат отменённого бронирования в корзину.
- Перед возвратом в корзину проверяются существование рейса, статус и доступные места; для Firebase-рейсов цена и данные синхронизируются с актуальными данными Firestore.
- Добавлено «Удалить из истории»: билет скрывается для пользователя через `hiddenFromUser`, но сохраняется в Firestore для истории администратора.
- Добавлена запись `booking_returned_to_cart` в журнал действий.
- Обновлены Firestore Rules для безопасного возврата в корзину и скрытия отменённых билетов.
